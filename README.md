# 🎮 C++ Console Games

## Description
Interactive console-based games developed in C++ to demonstrate logic implementation, randomized events, and real-time state evaluation. 

## Features
* **Math Quiz:** Customizable difficulty levels and arithmetic operations with performance summaries.
* **Rock Paper Scissors:** Randomized computer moves, round limits, and score tracking.
* **Replayability:** Game loops with continuous rematch logic.

## Technologies Used
* C++
